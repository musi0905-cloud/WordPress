# 17_GOVERNANCE/reports

| 파일 | 내용 |
|---|---|
| `GOVERNANCE_REPORT.md` | 전체 Governance Run 요약 (형식은 "17. GOVERNANCE REPORT FORMAT") |
| `CHANGE_CONTROL_REPORT.md` | Change Proposal/Change Set 처리 현황 요약 |
| `RELEASE_REPORT.md` | Release별 상세 리포트 (형식은 "16. RELEASE REPORT FORMAT") |
| `ROLLBACK_REPORT.md` | Rollback 실행 이력과 사유 |
| `PROPOSAL_REPORTS/` | Proposal별 상세 리포트 |

Release Report는 Constitution 검토, 영향도/위험도 분석, Sandbox 검증, WF-10 결과, Limited Rollout 결과, Rollback 계획을 모두 포함해야 하며, Secret이나 인증정보는 어떤 리포트에도 포함하지 않는다.
