# AI 글쓰기 패널 (My AI Writer)

구텐베르크 편집기 오른쪽에 AI 글쓰기 사이드바 패널을 추가하는 워드프레스 플러그인입니다. 빌드 과정 없이 zip 업로드만으로 설치됩니다.

## 설치 방법

1. `my-ai-writer` 폴더를 zip으로 압축합니다.
2. 워드프레스 관리자 → 플러그인 → 새로 추가 → 플러그인 업로드에서 zip 파일을 업로드합니다.
3. 업로드 후 "활성화"를 클릭합니다. (npm/webpack 등 별도 빌드 불필요)

## 초기 설정 방법

1. 관리자 메뉴에서 설정 → "AI 글쓰기 패널"로 이동합니다.
2. 기본 엔진(Claude/OpenAI/Gemini)을 선택하고, 사용할 엔진의 API 키와 모델명(글쓰기용)을 입력한 뒤 저장합니다.
3. 썸네일 이미지를 생성하려면 OpenAI 또는 Gemini의 API 키와 **이미지 모델명**(예: `gpt-image-1`, `gemini-2.5-flash-image`)도 입력합니다. Claude는 이미지 생성 API가 없어 썸네일 엔진으로 선택할 수 없습니다.
4. 글 편집 화면을 열면 오른쪽 사이드바에 "AI 글쓰기 도우미" 패널이 나타납니다. 주제를 입력해 글을 생성하거나, 썸네일 탭에서 스타일(포스터/매거진/인포그래픽/일러스트/타이포그래피/그라데이션/브랜딩)과 생성 엔진을 골라 이미지를 만들어 삽입할 수 있습니다.

API 키는 서버(옵션 테이블)에만 저장되며 브라우저로 전송되지 않습니다. 모든 AI 호출은 `POST /wp-json/maiw/v1/generate`(글쓰기)와 `POST /wp-json/maiw/v1/generate-thumbnail`(썸네일 이미지) 서버측 REST 라우트에서만 이뤄집니다.

### 썸네일 이미지 생성 방식

썸네일은 실제 AI 이미지 생성(OpenAI Images API 또는 Gemini 이미지 모델)으로 배경을 만들고, 그 위에 제목 텍스트는 브라우저 캔버스로 오버레이하는 하이브리드 방식입니다. AI에게는 "텍스트를 그리지 말라"고 명시적으로 지시해 한글이 깨지는 문제를 피합니다. 서버는 항상 base64 data URI로 이미지를 반환합니다(캔버스 내보내기가 cross-origin으로 막히는 것을 방지).
