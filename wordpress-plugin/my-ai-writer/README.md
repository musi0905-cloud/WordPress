# AI 글쓰기 패널 (My AI Writer)

구텐베르크 편집기 오른쪽에 AI 글쓰기 사이드바 패널을 추가하는 워드프레스 플러그인입니다. 빌드 과정 없이 zip 업로드만으로 설치됩니다.

## 설치 방법

1. `my-ai-writer` 폴더를 zip으로 압축합니다.
2. 워드프레스 관리자 → 플러그인 → 새로 추가 → 플러그인 업로드에서 zip 파일을 업로드합니다.
3. 업로드 후 "활성화"를 클릭합니다. (npm/webpack 등 별도 빌드 불필요)

## 초기 설정 방법

1. 관리자 메뉴에서 설정 → "AI 글쓰기 패널"로 이동합니다.
2. 기본 엔진(Claude/OpenAI/Gemini)을 선택하고, 사용할 엔진의 API 키와 모델명(글쓰기용)을 입력한 뒤 저장합니다.
3. 썸네일 이미지를 생성하려면 OpenAI 또는 Gemini의 API 키와 **이미지 모델명**(예: `gpt-image-1`, `gemini-2.5-flash-image`)도 입력합니다. Claude는 이미지 생성 API가 없어 썸네일 엔진으로 선택할 수 없습니다.
4. 글 편집 화면을 열면 오른쪽 사이드바에 "AI 글쓰기 도우미" 패널이 나타납니다. 상단의 **포커스 키워드**는 두 탭(AI 글쓰기/AI 썸네일)과 스키마 생성이 함께 참고하는 SEO 대상 키워드입니다.

API 키는 서버(옵션 테이블)에만 저장되며 브라우저로 전송되지 않습니다. 모든 AI 호출은 다음 서버측 REST 라우트에서만 이뤄집니다.

- `POST /wp-json/maiw/v1/generate` — 글쓰기 (주제/글 유형/언어/말투/분량)
- `POST /wp-json/maiw/v1/generate-thumbnail` — 썸네일 이미지
- `POST /wp-json/maiw/v1/generate-schema` — 스키마 마크업(JSON-LD)

### AI 글쓰기

주제 키워드, 글 유형(정보·가이드/유틸리티/정책·안내/리뷰/목록형/뉴스·트렌드), 언어(한국어/English/日本語/中文), 말투, 분량을 고르고 "AI 콘텐츠 생성"을 누르면 미리보기 없이 바로 편집기의 제목·본문에 반영됩니다. 다시 생성하면 편집기 내용을 새 결과로 덮어씁니다.

### AI 썸네일

주제 키워드, 생성 방식(OpenAI/Gemini), 스타일(포스터/매거진/인포그래픽/일러스트/타이포그래피/그라데이션/브랜딩)을 고르면 실제 AI 이미지 생성(OpenAI Images API 또는 Gemini 이미지 모델)으로 배경을 만들고, 그 위에 제목 텍스트는 브라우저 캔버스로 오버레이하는 하이브리드 방식입니다. AI에게는 "텍스트를 그리지 말라"고 명시적으로 지시해 한글이 깨지는 문제를 피합니다. 서버는 항상 base64 data URI로 이미지를 반환합니다(캔버스 내보내기가 cross-origin으로 막히는 것을 방지). Claude는 이미지 생성 API가 없어 이 목록에서 제외됩니다.

### AI 스키마 마크업

AI 썸네일 탭 하단에서 스키마 타입(기사/상품리뷰/자주 묻는 질문)을 고르고 "본문 내용으로 생성하기"를 누르면, 현재 글 본문을 근거로 AI가 schema.org JSON-LD를 만듭니다. 날짜·작성자·대표이미지·URL 같은 사실 필드는 AI가 아니라 실제 글 데이터로 채웁니다(사실이 아닌 평점·질문을 지어내지 않도록 프롬프트에서도 명시). 생성된 JSON-LD는 포스트 메타에 저장되고, 해당 글이 게시된 페이지의 `<head>`에 `wp_head` 훅으로 자동 출력됩니다(Rank Math/Yoast와 동일한 방식) — 편집기 본문에는 삽입되지 않습니다.
