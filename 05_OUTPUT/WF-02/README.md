# 05_OUTPUT/WF-02

WF-02_KNOWLEDGE_ENGINEERING 실행 시 생성되는 종합 리포트를 보관한다.

파일명 규칙: `{YYYY-MM-DD}_KNOWLEDGE_REPORT.md`

각 리포트는 해당 실행 회차의 6개 섹션(Knowledge Report, Knowledge Graph, Content DNA, Decision Tree, Template Graph, Updated Rule Library)을 `02_WORKFLOW/WF-02_KNOWLEDGE_ENGINEERING.md`의 "OUTPUT FORMAT" 순서대로 포함한다.

누적 자산(Content DNA, Knowledge/Pattern/Template Graph, Decision Tree 전체)은 `06_MEMORY/KNOWLEDGE_LIBRARY/`에 저장되며, 이 디렉토리의 파일은 "실행 1회분"의 요약본이다.
