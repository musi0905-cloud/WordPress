# 05_OUTPUT/WF-01

WF-01_REFERENCE_ANALYSIS 실행 시 생성되는 종합 리포트를 보관한다.

파일명 규칙: `{YYYY-MM-DD}_REFERENCE_REPORT.md`

각 리포트는 해당 실행 회차의 6개 섹션(Reference Report, Rule Library, Pattern Library, Template Library, Quality Report, Improvement Note)을 `02_WORKFLOW/WF-01_REFERENCE_ANALYSIS.md`의 "OUTPUT FORMAT" 순서대로 포함한다.

누적 자산(Rule/Pattern/Template Library 전체, REF-ID별 상세 리포트)은 `06_MEMORY/`에 저장되며, 이 디렉토리의 파일은 "실행 1회분"의 요약본이다.
