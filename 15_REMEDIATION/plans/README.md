# 15_REMEDIATION/plans

Case별 Remediation Plan을 영역별로 보관한다 (STEP 11 REMEDIATION PLAN 참조).

| 하위 디렉토리 | 내용 |
|---|---|
| `content/` | 콘텐츠 수정 계획 (저가치/중복/부족 콘텐츠, STEP 13) |
| `site/` | 사이트 구조 수정 계획 (Navigation/Policy Page/Trust 요소, STEP 14) |
| `technical/` | 기술 및 색인 수정 계획 (Robots/Noindex/Canonical/Sitemap/HTTP, STEP 15) |
| `policy/` | 정책·신뢰 요소 수정 계획 (STEP 16) |
| `reapplication/` | 재신청 준비 계획 (STEP 23) |

모든 계획은 실행(`assigned_workflow`), 검증(`validation_method`), 롤백(`rollback_method`) 경로를 함께 정의해야 한다.
