# PATTERN LIBRARY

Content OS 프로젝트의 누적 패턴 원장(Ledger).

Pattern은 Rule보다 큰 상위 개념이다. 서로 연관된 여러 Rule을 하나의 상위 구조 패턴으로 묶어 관리한다.

카테고리: SEO Pattern | UX Pattern | Layout Pattern | Content Pattern | Navigation Pattern | Conversion Pattern

이 파일은 append-only이다. Pattern은 절대 삭제하지 않으며, 상태(Deprecated / Merged / Replaced)로만 관리한다.

각 패턴의 형식은 `02_WORKFLOW/WF-01_REFERENCE_ANALYSIS.md`의 "Pattern Entry Format"을 따른다.
