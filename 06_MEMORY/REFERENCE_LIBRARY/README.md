# REFERENCE LIBRARY

참고 사이트별 구조 분석 원본을 보관한다 (원문 문장, 표현, 문체, 콘텐츠는 절대 포함하지 않음).

WF-01_REFERENCE_ANALYSIS가 사이트 1개를 분석할 때마다 이 디렉토리에 `{REF-ID}.md` 파일을 1개씩 생성한다.

파일명 규칙: `REF-001.md`, `REF-002.md` ...

각 파일은 WF-01의 STEP 01~05, 09, 10 결과를 아래 섹션으로 포함한다.

- Validation (STEP 01)
- Site Architecture Analysis (STEP 02)
- Article Structure Analysis (STEP 03)
- SEO Pattern Analysis (STEP 04)
- UX Pattern Analysis (STEP 05)
- Quality Evaluation — Reference Score /100 (STEP 09)
- Improvement Note — 구조적 개선 여지만 기록, 콘텐츠 개선안 금지 (STEP 10)

상세 절차와 각 섹션의 정확한 규격은 `02_WORKFLOW/WF-01_REFERENCE_ANALYSIS.md`를 따른다.
