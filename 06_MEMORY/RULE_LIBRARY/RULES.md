# RULE LIBRARY

Content OS 프로젝트의 누적 규칙 원장(Ledger).

Rule은 개별 구조 규칙이다. 여러 Rule이 상위 개념으로 묶이면 `06_MEMORY/PATTERN_LIBRARY/PATTERNS.md`의 Pattern이 되고, 반복되는 문서 골격은 `06_MEMORY/TEMPLATE_LIBRARY/TEMPLATES.md`의 Template이 된다.

이 파일은 append-only이다. 규칙은 절대 삭제하지 않으며, 상태(Deprecated / Merged / Replaced)로만 관리한다.

각 규칙의 형식(Title/Category/Description/Reason/Applicability/Exception/Priority/Evidence Count/Status/Created/Source Workflow)은 `02_WORKFLOW/WF-01_REFERENCE_ANALYSIS.md`의 "Rule Entry Format"을 따른다.
