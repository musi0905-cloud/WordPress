# WF-01 입력: 참고 사이트 목록

WF-01_REFERENCE_ANALYSIS가 분석할 벤치마킹 블로그/사이트 목록.

각 항목은 아래 형식을 따른다.

```
- id: REF-XXX
  source: <URL 또는 원문 텍스트 위치>
  topic: <주제/카테고리>
```

id는 비워두면 WF-01 실행 시 자동으로 다음 번호가 부여된다.

규칙(Rule)으로 승격되려면 최소 2개 이상의 서로 다른 사이트에서 공통 구조가 발견되어야 하므로,
가능하면 동일 주제의 참고 사이트를 2개 이상 등록한다.
