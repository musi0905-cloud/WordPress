# 12_TEST/reports

WF-10 Test Run이 생성하는 보고서를 보관한다 (`02_WORKFLOW/WF-10_SYSTEM_VALIDATION.md`의 "6. REQUIRED OUTPUT" 참조).

- `SYSTEM_VALIDATION_REPORT.md` / `.json` — 전체 검증 종합 리포트
- `TEST_SUMMARY.md` — 테스트 요약
- `FAILED_TESTS.md` — 실패/차단 테스트 목록
- `SECURITY_TEST_REPORT.md`, `WORKFLOW_CONTRACT_REPORT.md`, `END_TO_END_TEST_REPORT.md`, `RECOVERY_TEST_REPORT.md`, `REGRESSION_TEST_REPORT.md` — 영역별 리포트
- `ACCEPTANCE_REPORT.md` — 최종 판정 (`ACCEPTED` / `ACCEPTED_WITH_WARNINGS` / `CONDITIONALLY_ACCEPTED` / `REJECTED` / `BLOCKED`)
