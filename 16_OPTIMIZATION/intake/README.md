# 16_OPTIMIZATION/intake

성과 기반 Optimization Candidate의 원본 입력을 유형별로 보관한다 (STEP 04 CANDIDATE DETECTION 참조).

| 하위 디렉토리 | 내용 |
|---|---|
| `performance_candidates/` | 노출/CTR/순위/참여 기반 후보 원본 (WF-12 성과 데이터에서 파생) |
| `freshness_candidates/` | 정보 최신성(날짜/가격/정책/기능/통계) 문제 후보 원본 |
| `manual_candidates/` | 사람이 직접 입력한 최적화 후보 |
| `imported/` | 외부에서 가져온(import) 원본 후보 사본 |

Candidate는 실제 성과 데이터로 뒷받침되지 않으면 승인되지 않는다.
