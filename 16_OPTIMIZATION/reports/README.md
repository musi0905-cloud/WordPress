# 16_OPTIMIZATION/reports

| 파일 | 내용 |
|---|---|
| `OPTIMIZATION_REPORT.md` | 전체 Optimization Run 요약 |
| `CONTENT_OPPORTUNITY_REPORT.md` | 탐지된 Optimization Candidate와 기회 요약 |
| `EXPERIMENT_RESULT_REPORT.md` | 완료된 Experiment의 결과 요약 (형식은 "16. EXPERIMENT REPORT FORMAT") |
| `EXPERIMENT_REPORTS/` | Experiment별 상세 리포트 |

Experiment 결과는 검색 수요 변화, 계절성, 사이트 전체 변화, 동기간 다른 수정 등 교란 요인을 함께 기록하며, 상관관계를 인과관계로 확정하지 않는다.
