# 14_PERFORMANCE/reports

- `PERFORMANCE_REPORT.md` — 실행 종합 리포트 (게시/색인/검색/참여/클러스터/Template·Rule·Workflow/AdSense/수익/이상징후/Alert)

- `ADSENSE_APPROVAL_REPORT.md` — 사이트별 애드센스 신청/승인/거절/재신청 이력
- `CONTENT_PERFORMANCE_REPORT.md` — 콘텐츠별 상세 성과
- `SITE_HEALTH_REPORT.md` — 사이트 기술 건강도
- `PERIODIC/` — 정기(주간/월간) 리포트 아카이브
